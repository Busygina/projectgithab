# Book Tracker

**Автор:** Лиза Бусыгина

## Описание программы

Book Tracker — это десктопное приложение для управления списком прочитанных книг. 
Позволяет:
* добавлять книги с указанием названия, автора, жанра и количества страниц;
* фильтровать книги по жанру и минимальному количеству страниц;
* сохранять и загружать данные в формате JSON
