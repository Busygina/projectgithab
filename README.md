# Random Task Generator (Генератор случайных задач) 🎯

Простое десктопное приложение на Python с использованием библиотеки `tkinter`, которое помогает бороться с прокрастинацией, выбирая для вас случайное занятие из списка.

## Особенности
- **Генерация задачи:** Выбирает случайное дело из доступного списка.
- **Фильтрация:** Можно просматривать задачи по категориям (учёба, работа, спорт, отдых).
- **Добавление своих задач:** Вы можете расширять список дел прямо через интерфейс.
- **Сохранение данных:** Все задачи сохраняются в файл `tasks.json` и доступны после перезапуска.
- **История:** Отображает лог последних сгенерированных задач в текущей сессии.

## Использование
1. Нажмите кнопку **"Сгенерировать задачу"**, чтобы получить случайное задание.
2. Используйте **"Фильтр по типу"**, чтобы отсортировать список задач в окне просмотра.
3. Чтобы добавить свою задачу:
   - Введите текст в нижнее поле.
   - Выберите категорию.
   - Нажмите **"Добавить в список"**.

## Структура проекта
- `main.py` — основной код приложения.
- `tasks.json` — файл базы данных задач (создается автоматически при первом запуске).
