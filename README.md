## Описание

Приложение позволяет:
* генерировать случайные задачи из предопределённого списка;
* добавлять новые задачи с указанием типа (учёба, работа, спорт, отдых);
* просматривать историю всех сгенерированных задач;
* фильтровать историю по типу задачи;
* сохранять историю задач между запусками приложения (в формате JSON).

## Функциональность

* **Кнопка «Сгенерировать задачу»** — выбирает случайную задачу из списка и отображает её в верхней части окна.
* **История задач** — список всех сгенерированных задач отображается в нижней части окна.
* **Фильтр по типу** — выпадающий список для фильтрации задач по категориям: «все», «учёба», «работа», «спорт», «отдых».
* **Добавление новых задач** — поле ввода для текста задачи и выпадающий список для выбора типа.
* **Валидация ввода** — проверка на пустую строку при добавлении новой задачи.
* **Сохранение данных** — история задач сохраняется в файле `tasks.json` между запусками программы.

## Технологии

* Python 3.x
* Библиотека `tkinter` — для создания графического интерфейса (GUI).
* Библиотека `random` — для выбора случайной задачи.
* Библиотека `json` — для сохранения и загрузки истории задач.
* Библиотека `os` — для проверки существования файла с историей.
